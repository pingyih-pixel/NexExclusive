# NexExclusive

[![build](https://github.com/pingyih-pixel/NexExclusive/actions/workflows/build.yml/badge.svg)](https://github.com/pingyih-pixel/NexExclusive/actions/workflows/build.yml)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**简体中文** · [English](README.en.md)

给网易云音乐 PC 客户端加上 WASAPI 独占输出：音频绕过 Windows 混音器，以音源本身的采样率直接交给声卡。适用于 Windows 10/11 x64。

<!-- TODO: 补一张设置面板截图，存为 docs/panel.png，再在这里引用 -->

适合使用外置 DAC、耳放，希望 44.1 kHz 的曲目就以 44.1 kHz 播出的听众。

## 特性

- **独占输出**：音频不经过系统混音器，没有那层强制的 48/96 kHz 重采样。
- **跟随音源**：44.1 的曲目以 44.1 播放，96 的曲目以 96 播放。设备拒绝这个格式时才做转换，面板里会标明本次是「直通」还是「转换过」。
- **切换交接**：切歌、拖动进度、更换输出设备时，模块会重建或迁移独占流；连续性仍以当前设备与路径的实测记录为准。
- **装好即常驻**：一键安装，托盘常驻，开机自启；客户端重启或页面刷新后自动重新接入。

## 安装前须知

安装之前，下面三件事值得先读完。

**Defender 会隔离程序。** 宿主程序用 `CreateRemoteThread` 把 DLL 加载进客户端进程，这个行为本身触发了 Defender 的行为检测（`Behavior:Win32/DefenseEvasion.A!ml`）。程序会在 30–60 秒内被隔离，快捷方式、自启项和卸载项也一并被删除。项目认定这是误报，申诉材料见 [docs/defender-false-positive.md](docs/defender-false-positive.md)，源码全部公开，可以自行核对。

安装前，以管理员身份打开 PowerShell，给两个文件加上排除项：

```powershell
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\NexExclusive\NexExclusive.exe"
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\NexExclusive\nexsink.dll"
```

直接从 zip 展开出的目录运行时，同样给该目录下的这两个文件加上。愿意加排除项才使用本程序；也请保持实时保护开启。

**与网易公司无关。** 这是非官方工具。往第三方客户端进程里加载 DLL，有违反其用户协议的风险，后果自负。

**系统与设备。** 需要 Windows 10/11 x64。播放设备要在 Windows 声音属性的「高级」页里允许应用程序独占控制。客户端版本只验证过 3.1.42.205594 和 3.1.43.205627，其余版本见[兼容性](#兼容性)。

## 下载与首次运行

**目前只有预发布（Pre-release）。** 程序没有代码签名，Defender 误报也还没有结论，装完可能被隔离，所以先以预发布形式提供，原因记录在 [docs/ROADMAP.md](docs/ROADMAP.md)。取得程序有三种途径：

1. 在 [Releases](https://github.com/pingyih-pixel/NexExclusive/releases) 下载，二选一：
   - **安装版** `NexExclusive-x.y.z-setup.exe`：装到 `%LOCALAPPDATA%\NexExclusive`，登记开机自启、开始菜单和卸载项，不需要管理员权限；
   - **便携版** `NexExclusive-x.y.z.zip`：解压后直接运行 `NexExclusive.exe`。
2. 打开 [Actions](https://github.com/pingyih-pixel/NexExclusive/actions/workflows/build.yml)，进入最近一次成功的构建，下载产物 `NexExclusive-package`（下载产物需要登录 GitHub）。
3. 自行构建，步骤见 [docs/BUILDING.md](docs/BUILDING.md)。

下载后先核对哈希，输出应与 `SHA256SUMS.txt` 中对应的一行一致：

```powershell
Get-FileHash .\NexExclusive-x.y.z.zip -Algorithm SHA256
```

首次运行：

1. 展开 zip，双击 `NexExclusive.exe`。程序会询问是否安装：装到 `%LOCALAPPDATA%\NexExclusive`，写入开机自启，建立开始菜单快捷方式；安装步骤不需要管理员权限。
2. 安装完成后打开 NexExclusive 主窗口并拉起客户端。之后照常打开网易云即可。
3. 主窗口最小化或关闭时缩到右下角托盘，双击托盘图标或再次运行 NexExclusive 回到窗口；开机自启时只进托盘。托盘右键菜单：打开 NexExclusive / 暂时改为共享 / 打开网易云音乐 / 退出。

主窗口分五页：**概览**（现在是独占、共享还是已让出，信号链「音源 → 网易云 → 设备」和改了什么）、**输出**（独占开关、策略、设备、格式与转换）、**和别的应用**（暂停后让出、别的应用想出声时询问、暂时改为共享、记住的选择）、**播放器**（网易云的版本与接管状态、是否一起启动、是否在网易云里显示面板）、**关于**（开机自启、关闭到托盘、日志、备用面板通道、卸载）。跟随系统浅色/深色。窗口用系统自带的 WebView2 显示，没有 WebView2 时退回简易设置窗口。

命令行：

```
NexExclusive.exe --install [--client "D:\...\cloudmusic.exe"]
NexExclusive.exe --show
NexExclusive.exe --uninstall
NexExclusive.exe --help
```

客户端装在非默认位置、程序探测不到时，用 `--client` 指定 `cloudmusic.exe` 的路径。
`--show` 会复用已有的网易云主进程并尝试呼出窗口；没有进程时才启动新实例。若日志出现 `OpenProcess(<pid>) 失败 5`，请结束普通宿主后以管理员身份启动宿主。

## 设置面板

设置页会新增一个独立的「NexExclusive」入口，里面集中显示独占状态、输出模式、输出规格和兼容处理。播放页仍保留「独占输出」面板，便于从当前播放设置快速查看。

播放页网易云原生的「无损」标签属于服务端质量选择，NexExclusive 不会修改它。音频规格收纳在 NexExclusive 设置窗口，显示源规格、客户端 PCM、独占端点和 `Bit-perfect` / 转换状态；尚未取得独立源元数据时显示「源规格：未取得」。客户端日志里的 `32 bit` 是客户端 PCM 容器或浮点传输格式，不能直接当成服务端源文件位深。

| 项 | 作用 | 何时调整 |
| --- | --- | --- |
| 启用独占 | 总开关，关闭后回到客户端默认输出 | 想临时对比共享模式的声音，或排查问题时 |
| 位深协商 | 原率优先跟随设备可用格式；严格原样跟随客户端格式 | 不在界面固定选择，避免人为改写源格式 |
| 采样率 | 跟随音源（默认），或强制 44.1 / 48 / 88.2 / 96 kHz | 想让所有曲目统一输出到同一个采样率时 |
| 重采样策略 | 带宽优先（默认）或整数比优先 | 88.2 kHz 音源在设备只接受 44.1 / 48 / 96 kHz 时，想优先 44.1 kHz 时调整 |
| 缓冲帧数 | 自动，或 512–4096 | 出现爆音时调大，在意延迟时调小 |
| 输出策略 | `原率优先（推荐）` 先尝试源格式，设备拒绝时继续使用独占转换；`严格原样` 只接受源格式 | 日常播放使用原率优先；验证设备是否支持源格式时使用严格原样 |
| 兼容转换 | 原率优先模式下允许独占端点转换采样率或位深 | 默认开启；严格原样会自动关闭 |
| 抖动 | 关闭 / 开启 / 自动 | 默认自动，在降低位深或做过重采样时生效，一般不用动 |
| 开头淡入 | 默认关闭，可选 3–20 ms | 起播有爆音时开启；开启后每次开始播放的前几毫秒不再是原样，面板会标出 |
| 共享回退 | 不打开共享输出 | 当前产品路径固定关闭，避免把共享输出误认为独占 |
| 独占输出设备 | 默认「跟随网易云」；也可固定到某个播放设备 | 想让网易云的独占输出固定走某个 DAC 时；选定设备拔出或不可用时自动回到网易云的设备 |
| 独立音频宿主 | 将独占端点和实时提交移到 `NexAudioHost.exe`；DLL 先完成协商、转换（原率优先时）与抖动，再把最终 PCM 交给宿主 | 默认关闭，属于实验引擎；暂停、拖进度和开播静音由宿主执行 |
| 暂停时让出声卡 | 不让出（默认）/ 暂停 10 秒、30 秒、1 分钟、5 分钟后 | 独占时暂停也占着声卡，别的应用没有声音。开启后暂停够久就把声卡让出去，继续播放时再接管，进度不变 |
| 别的应用出声时改走共享 | 默认关闭 | 开始或继续播放时，如果别的应用正在这个设备上出声，就和它一起走系统混音器（**不是原样**，面板会显示「共享输出」）。网易云独占期间有别的应用开始播放（按 Windows 媒体会话判断），会弹窗问你：别的音乐播放器问「把独占交给它吗」（是 → 网易云暂停并让出声卡），浏览器、视频这类问「关闭独占、一起播放吗」（是 → 网易云改走共享）。勾「记住我的选择」后这个应用不再询问；30 秒不选按保持独占处理。别的应用停止播放 10 秒后，下一次继续播放时回到独占 |

同样的设置写在 `hook.cfg` 里（纯文本 `key=value`），面板修改后先留在草稿中。「保存（下一首应用）」会立即写入配置并保持当前曲目的播放进度，下一首或下一次音频流建立时读取新配置。「保存（当前曲目重开应用）」会先保存未提交修改，再通过客户端正常的暂停/恢复路径重建音频流；当前曲目位置和原来的播放/暂停状态都会保留。`audiohost=1` 需要发布包里的 `NexAudioHost.exe`；宿主收到的是 DLL 已经转换好的最终 PCM（严格原样时即客户端原格式，原率优先时可能是重采样或降位深后的 PCM），宿主本身不做任何样本处理。

`hook.cfg` 还有几项面板不显示的高级设置，手动加一行即可，面板保存时会原样保留：

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `prime` | `1` | 新流开播前先垫一个设备缓冲的静音，避免 DAC 唤醒时吞掉开头 |
| `resync_ms` | `200` | 44.1k 族与 48k 族之间切换、或冷启动唤醒闲置的 DAC 时额外垫的静音（0–2000 ms），给 DAC 换晶振或打开输出级的时间 |
| `settle_ms` | `600` | 冷启动（之前 2 秒内没出声也没开流）时，先等网易云把格式定下来再开声卡，避免开播时 DAC 连切两次采样率发出咔哒声；`0` = 不等 |
| `event` | `0` | `0` = 定时轮询（默认）；`1` = 独占优先用事件驱动，驱动拒绝时自动回退定时轮询 |
| `memlock` | `1` | 把音频缓冲锁在内存里，避免缺页造成断音 |
| `dedicated_core` | `0` | 让输出线程独占一个快核心 |
| `process_priority` | `0` | 接管期间提高网易云进程优先级 |
| `host_ring_ms` | `500` | 独立音频宿主的环形缓冲深度（200–4000 ms）；越深越抗卡顿，但网易云自己的音量调节要晚这么久才生效 |
| `share_quiet_ms` | `3000` | 开启「别的应用出声时改走共享」时，别的应用要安静多久才回到独占（500–60000 ms） |
「暂时改为共享」（主窗口「和别的应用」页或托盘）随时可以手动让出（不受上面开关限制），用于检测不到的应用（不接入 Windows 媒体会话的播放器）；关掉后下次继续播放时回到独占。记住的选择存在程序目录的 `apps.cfg`，在主窗口「和别的应用」页可以改或删。注意：浏览器在网易云独占期间开始播放的话，会改用静音的假设备，关闭独占之后也不会自己恢复，需要刷新或重新打开页面。
| `log` | `1` | 写 `sink.log`；`0` 关闭（日志由后台线程写盘，不占用音频线程） |
严格原样的验证对象是「客户端 PCM → 独占端点 PCM」；设备支持源格式时可以做到 bit-perfect 输出，但它不代表网易云解码前的源文件已经完成 bit-perfect 证明。设备不支持源格式时，面板会提示切换到原率优先，当前曲目不会退回共享输出。音频规格只在 NexExclusive 设置窗口中展示，源元数据尚未取得时显示「源规格：未取得」。远程 audiohost 已改用 Host 的 `IAudioClock` 位置和 EOS 等待窗口，长时间连续播放仍在单变量验收阶段。

## 工作原理

客户端没有运行时，宿主程序会先尝试使用客户端的调试启动路径；当前未验证版本优先保证网易云窗口出现，再由看护循环处理主进程。随后宿主用 `CreateRemoteThread` 加 `LoadLibraryA` 把 `nexsink.dll` 加载进客户端进程。DLL 在进程内挂接 `IMMDevice` 与 `IAudioClient` 的 vtable：客户端协商输出格式时，由 DLL 依据设备在独占模式下的真实能力作答，缓冲、重采样和切换时的交接也在 DLL 里完成。

设置面板默认由 `nexui.dll` 在客户端页面内加载：宿主把它注入网易云的渲染子进程，它只在那里动作，不需要调试端口。挂接不可用时（例如客户端换了 CEF 版本），用 NexExclusive 主窗口改设置即可，它和面板改的是同一份 `hook.cfg`。旧的 CDP 回退（经本机 9333 调试端口注入脚本）默认关闭：端口开着时本机任何进程都能在客户端页面里执行脚本、拿到登录状态；确实需要时在 `host.cfg` 写 `cdp=1` 再重启宿主。面板的「保存（当前曲目重开应用）」不需要 CDP，宿主通过网易云自己的 Windows 媒体会话暂停再继续。面板与宿主之间走 `127.0.0.1:9334` 上的配置接口，读写 `hook.cfg` 与 `ui.json`。音频 DLL 与界面 DLL 互不依赖，任何一方失效都不影响另一方。

程序运行期间，本机回环地址上开着 9334 端口（`cdp=1` 时还有 9333），同一台机器上的其他进程可以访问。宿主的全部网络通信都发生在回环地址上，DLL 本身不含网络代码。客户端的文件不会被修改。

| 项 | 已验证 | 尚未验证 |
| --- | --- | --- |
| 系统 | Windows 11 26200 家庭版 | Windows 10 22H2 |
| 客户端 | 3.1.42.205594、3.1.43.205627 | 其他版本。日志里会标「未经验证」；客户端更新若改动了内部布局，会出现没有声音也没有报错的情形 |

## 已知问题

- **Defender 误报**：见[安装前须知](#安装前须知)。
- **独占下调不了软件音量**：WASAPI 的固有限制。端点有硬件音量节点时，系统音量条仍然有效。本项目明确不做模块侧的数字衰减，不拿比特换音量。
- **无管理员权限卸载时会留下 exe**：程序正被自己占用，此时无法登记「重启后删除」。关掉程序后手动删除目录即可。
- **设置面板仍缺少跨版本回归**：面板默认由 `nexui.dll` 在页面内加载（CEF 91），已验收设置入口、保存与 `hook.cfg` 双向同步、刷新后不重复挂载；不同网易云版本仍需单独确认节点选择器与 CEF 版本。
- **88.2 kHz 的音源**：在只支持 44.1 / 48 / 96 的设备上会转换到 96 kHz，这是「保带宽」的取舍，代价是一次非整数比的重采样。
- **远程播放正确性仍在审计**：远程路径现在读取 Host 的设备时钟快照，EOS 会等待环排空和设备时钟越过尾部；暂停、换轨、seek 与长时间播放仍需真机验收。详见 [docs/AUDIO_CORRECTNESS_AUDIT_2026-11-16.md](docs/AUDIO_CORRECTNESS_AUDIT_2026-11-16.md)。
