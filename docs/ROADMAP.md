# 离「完善」还差什么

这份文件回答一个问题：**现在的 1.0.0 能不能算完成版？**

答案分两种口径，别混着说：

- **「在我这台机器、这个客户端版本、这个耳机上稳定用」→ 是。** 独占接管、切歌、
  拖进度、切端点、一键安装、托盘常驻、卸载，都有实测证据。
- **「可以发给任何人、插任何设备都能用」→ 不是。** 卡在下面 P0 第一条。

下面的清单按「影响面 × 修起来的代价」排序。P0 不解决，后面都只是自娱自乐。

---

## P0 · 不解决就不能对外分发

### 1. Defender 误报

`Behavior:Win32/DefenseEvasion.A!ml`（ThreatID 2147738096），30–60 秒内隔离
exe，连带删快捷方式、自启项、卸载项。触发点是 `WriteProcessMemory` +
`CreateRemoteThread` 这个行为本身。

- [ ] 向微软提交误报（材料已备好：`docs/defender-false-positive.md`）
- [ ] 若被打回，评估换成代理 DLL 注入（放客户端目录旁转发导出表，没有远程线程）
- [ ] 代码签名（能压 SmartScreen，压不住行为检测，但对申诉有帮助）

**验收**：在没加任何排除项的干净 Windows 11 虚拟机上，装完 10 分钟 exe 还在。

### 2. 未签名 + 无公开构建

- [x] 公开仓库（README / LICENSE / CI 已就绪）
- [x] CI 出包（`.github/workflows/build.yml`，与本地同一条 `release.sh`）
- [ ] 实际推上 GitHub 并跑通一次 CI
- [ ] 可选：代码签名

## P1 · 正确性与兼容性

### 3. 只在一个客户端版本上验过

唯一验证过的版本是 `3.1.42.205594`。注入靠 `IMMDevice` / `IAudioClient` 的
vtable 槽位，客户端大版本更新有可能改布局或改模块加载顺序——**会静默失效**。

现在的处理：日志里标「未经验证」，不硬拦（拦下来用户也没法用）。

- [ ] 至少再验 2 个客户端版本（一个旧版、一个最新版）
- [ ] 客户端更新后如果 vtable 变了，给出明确报错而不是「没声音」

**验收**：换一个客户端版本，日志能说清「哪一步没成」，而不是静默无声。

### 4. 只在一台机器上验过

Windows 11 26200 家庭版；端点只有 HyperX Cloud III（44.1/48/96）和
AudioQuest DragonFly MM3A（额外支持 88.2）。

- [ ] 另一台机器 / 另一个 Windows 版本（Win10 22H2 最有价值）
- [ ] 至少一种主板集成声卡（Realtek）和一种 HDMI 输出
- [ ] 352.8 / 384 kHz、多声道（5.1/7.1）——候选池里有，从未实测

### 5. 宿主侧没有自动化测试

19 组回归覆盖的是模块核心（vtable、环缓冲、重采样、生命周期、闸门）。
宿主侧——安装、卸载、托盘、单实例、跨目录跳转、版本探测——**全靠手工**。

- [ ] 把安装/卸载/单实例做成可脚本化的验收（装到临时目录、断言文件与注册表）
- [ ] CI 里跑（需要 Windows runner，已经有）

### 6. 88.2 的转换策略没定

现在候选顺序是「源率 → 最近的更高 → 从高到低更低」，所以 88.2 源在只支持
44.1/48/96 的设备上会落到 **96 kHz**（160:147 有理数比，保带宽）。

另一个选择是优先整数比 → **44.1 kHz**（2:1 抽取，最省，但砍掉 22.05k 以上）。

- [ ] 决定默认策略
- [ ] 若要可配，加 `src_prefer=bandwidth|simplicity`（默认保持现状）

**这不是 bug，是取舍。** 现在默认「保带宽」，代价是一次非整数比重采样。

## P2 · 功能缺口

### 7. 软件音量端点在独占下不可调

WASAPI 独占的固有限制。端点有硬件音量节点时系统音量条仍有效；纯软件音量的
端点（部分 HDMI、部分主板声卡）在独占下就是调不了。

**已决定不做模块侧数字衰减**（不拿比特换音量）。这是产品决策，不是待办。

### 8. 四条通路只做了一条

WASAPI 独占 ✅ ／ ASIO ❌ ／ OpenHome ❌ ／ DLNA ❌

面板原计划分「本机播放 / 网播播放」两个页签，本机页签里在 WASAPI 端点和
ASIO 驱动之间二选一。目前只有第一条。

### 9. 设置面板没做回归

`ui/panel.js` 能注入（日志 `界面脚本已就位`），但面板上的交互——切格式、
看当前协商结果、开关精简项——**最近没有系统回归过**。

- [ ] 面板状态与 `hook.cfg` 双向同步的验收
- [ ] 客户端页面刷新 / 切页后不重复挂载

### 10. 零碎

- [ ] 自定义托盘图标（现在是 `IDI_APPLICATION` 默认图标）
- [ ] 自动更新（现在要手动下新包）
- [ ] 界面/日志英文化（现在全中文）
- [ ] 卸载自删除（非管理员会留下 exe，已在 README 说明，未根治）

## 怎么判断「可以发了」

一份可执行的门槛，不是感觉：

1. 干净 Win11 虚拟机装完 10 分钟，exe 还在（Defender 不拦）
2. 三个不同客户端版本，两个不同声卡/耳机，都能出声且日志说清用了什么格式
3. 从零克隆 → `bash mod/build.sh test` 全 PASS → `bash release.sh` 出包，
   CI 上同样能跑通
4. README 里的「已知问题」没有一条会让人装完就懵

第 1 条是硬门槛，其余三条是质量线。
