# NexExclusive 主窗口设计

日期：2026-11-26　状态：界面已与用户确认，进入实现

## 为什么

NexExclusive 的功能已经超出「网易云里的一个设置面板」：独占/共享切换、暂停让出、别的应用想出声时询问与记住选择、播放器状态、诊断。设置原来散在网易云页面里的面板和托盘的简易窗口两处。用户要一个独立的主窗口：打开 NexExclusive.exe 就是它，最小化或关闭缩到托盘，双击托盘再打开；界面现代，接近 Windows 11 设置，带一点 Apple Music 的大标题感。

## 目标

- 打开 NexExclusive.exe 显示主窗口；最小化、关闭都缩到托盘，托盘双击或菜单「打开 NexExclusive」再显示；再次运行 exe 时把已有窗口叫到前台。开机自启时只进托盘、不弹窗。
- 五页：概览、输出、和别的应用、播放器、关于（内容见下）。跟随系统浅色/深色。
- 网易云里的面板保留不动（以后再决定去留）。
- 设置改完自动保存，底部提示「从下一首开始生效」并提供「立即应用到当前曲目」。

## 不做

- 不改音频模块（DLL）的行为；只读它已经通过控制块和日志给出的状态。
- 播放器页暂不做多播放器支持，只放网易云；更多播放器等后端方案定了再加。
- 「检查更新」先放按钮、暂不可用：更新方式取决于发布渠道（Release、Defender 误报），另定。
- 图标和名字不定，和改名一起做。

## 不能接受

- 主窗口打不开时设置就改不了：WebView2 不可用时退回原来的 Win32 设置窗口。
- 为主窗口打开新的对外端口或放宽本机接口的来源限制到任意网页。

## 方案（已选）

| 方案 | 取舍 | 结论 |
|---|---|---|
| **WebView2 内嵌网页界面** | 现代界面容易做、和网易云面板同一套技术；依赖 Win11/多数 Win10 自带的 WebView2 运行时，窗口打开时多几个 msedgewebview2 进程 | **选用** |
| 纯 Win32 自绘 | 无依赖，但做出同等观感工作量大数倍，两套界面代码 | 不选 |
| Edge `--app` 窗口 | 最省事，但无法缩到托盘，本质是浏览器窗口 | 不选 |

WebView2 不随包附带微软的 WebView2Loader.dll：宿主直接从已安装运行时的 `EBWebView\x64\EmbeddedBrowserWebView.dll` 调 `CreateWebViewEnvironmentWithOptionsInternal`（官方加载器做的也是这件事），用到的几个 COM 接口按槽位手写调用、先 QueryInterface 校验，和 `nexsmtc.h` 同一做法。找不到运行时或调用失败就退回 Win32 设置窗口。

## 界面（已确认）

Windows 11 设置风：左侧导航（顶部一张小状态卡），右侧大标题 + 一张张设置横条，系统强调蓝，原生样式的开关/下拉/按钮。

- **概览**：输出状态卡（独占输出中 / 共享输出中 / 已让出，设备、播放器、是否在播，按钮「暂时改为共享」）；信号链三站「音源 → 网易云 → 设备」＋一个结论标签（原样 / 位深转换 / 重采样 / 经系统混音器）＋一句说明，「详细参数」展开；常用：独占输出、暂停后让出声卡。
- **输出**：独占输出、输出策略、输出设备、独立音频宿主；格式：采样率、缓冲、设备不接受时的转换（兼容转换、重采样策略、抖动、淡入）。
- **和别的应用**：「现在」只在有别的应用出声时显示（带「回到独占」）；暂停后让出声卡、别的应用想出声时问我、暂时改为共享；记住的选择（应用、类型、选择可改、可删）。
- **播放器**：网易云卡片（版本、是否已接管、面板是否加载、打开网易云）；一起启动网易云、在网易云里显示设置面板。
- **关于**：项目介绍（文字占位）、版本与构建、检查更新（暂不可用）；开机自动启动、关闭窗口时缩到托盘；日志与程序目录、备用面板通道（9333）、卸载。

## 后端

本机配置服务 `127.0.0.1:9334` 增加主窗口的静态页面与接口；来源检查放行 `http://127.0.0.1:9334` 自己（页面由它提供），其他网页仍被拒。

- `GET /app/...`：`ui/app/` 下的页面文件。
- `GET /api/status`：在现有字段上补控制块快照（状态、是否在播、格式、路径、设备名、独立宿主）、是否手动改为共享、此刻在出声的别的应用、播放器信息（版本、是否已接管、面板是否加载）。
- `POST /api/control`：`share` / `exclusive`（等同托盘的暂时改为共享 / 恢复）。
- `GET/POST /api/apps`：记住的选择（读、改、删，写回 apps.cfg）。
- `GET/POST /api/host`：开机自启、关闭到托盘、一起启动网易云、在网易云里显示面板、CDP；版本、构建、安装目录、日志大小。
- `POST /api/action`：打开日志、打开程序目录、打开网易云、卸载（走现有卸载流程）。

## 留给实现者

- 主窗口隐藏时释放 WebView2（省内存），再显示时重建。
- 开机自启的 Run 值加 `--tray`；旧安装在启动时把 Run 值更新过来。
- 单实例：第二次运行把已有主窗口叫到前台。
- 网易云面板的显示开关用现有的 `nexui.disable` 机制。

## 验证

- 后端接口：宿主测试覆盖新增解析/写回逻辑；契约测试同步。
- 页面：宿主跑起来后在浏览器里直接打开 `http://127.0.0.1:9334/app/` 检查每一页与深浅色。
- WebView2：临时安装里启动宿主，用 WebView2 调试端口（仅测试时经环境变量打开）确认页面加载、标题正确；截取窗口画面检查。
